📖 How to Get a Webhook URL

🟣 Slack

  1. Go to Slack Incoming Webhooks
  2. Create a new app or use an existing one
  3. Enable "Incoming Webhooks" and add a new webhook
  4. Copy the webhook URL

🟦 Discord

  1. Open your Discord server settings
  2. Go to Integrations → Webhooks
  3. Click "New Webhook" and choose a channel
  4. Copy the webhook URL

🔵 Microsoft Teams

  1. In your Teams channel, click ⋯ → Connectors
  2. Search for "Incoming Webhook" and configure it
  3. Give it a name and copy the webhook URL

⚪ Generic

Any HTTP endpoint that accepts POST requests with a JSON body. CyberDash will send a payload with title, message, and items fields.
